# 附件｜视觉 / 舞台 / 五段短片

> 来源：Grok 4.6 视觉方案。会期仍按主方案 **8 月 14 日 16:30–18:00**（原稿 14:00 不采用）。  
> 气质：克制、轻、日常可戴。灯要暗一点，字要少一点，绿要薄一点。

## 1. 主 KV

- 主标题：万镜出征 · 九九决胜  
- 主句：**把光，戴进日常。**  
- 辅句：京东首销 · 海外定金 · 200 店 · 软件大版本 · 第 10000 副  
- 底：哑光黑 `#0B0C0E`  
- 钛金：`#C4B49A`，只用于边线、勋章、标题，覆盖 ≤ 8%  
- HUD 微绿：`#7CFFB2`，亮度压到 40–55%，只作细线与倒计时，禁止满屏霓虹  
- 正文暖白：`#F4F1EA`  
- 构图：正中一副侧光真机，镜腿一线微绿；背景是通勤／书桌／窗边，不是机甲。左右各留 18% 白。  
- 禁止：粗黑体口号墙、斜切科幻字、假数据大屏。

| 区 | 位置 | 要点 |

| 主舞台 | 上舞台 6.0×2.4 m | LED 只播 KV、短片、人名；窄桌放一副真机 |

## 3. 五段短片（各 15–20 秒，24fps，结尾 2 秒字幕）

禁炮火、禁股票动画、禁「碾压」。每段播完黑场 2 秒，当事人只准 40 秒。

**① 京东首销（18s）**  
晨光桌面未拆盒 → 开盒掂重量 → 镜片一闪微绿切到「已签收」（界面打码）→ 字幕「京东首销 · 第一副戴进日常」。

**② 海外定金（18s）**  
时区钟与确认邮件（金额姓名虚化）→ 不同城市街拍戴镜走路不看镜头 → 手写 postcard「deposit received」→ 「海外定金 · 先被世界轻轻点头」。

**③ 200 店（16s）**  
玻璃门推开、柜台上眼镜与绿植 → 店员递给顾客对镜一笑 → 地图 200 个淡绿点疏疏亮起 → 「200 店 · 可试、可戴、可带走」。

**④ 软件大版本（18s）**  
一行真实提交记录（不做代码雨）→ 薄界面：时间／导航／提醒，字号小 → 抬头看路界面淡出 → 「大版本 · 光在，界面不抢」。

**⑤ 第 10000 副（20s）**  
棉指套轻放镜框 → 铭牌 No.10000 → 托起穿过光圈落丝绒托盘 → 「第 10000 副 · 今天交到台上」。

## 4. 第 10000 副出场（采用总导演稿的器物，去掉正步与齐喊）

黑匣、红蜡封条、编号贴纸 NO.10000，钥匙由供应链持有。灯切暗 → 双手捧匣走中轴（平常步，不正步）→ 出征台中央 → 剪蜡开匣 → **静音 3 秒** → 镜腿未展开，托于黑绒垫 → 负责人举过眉心 3 秒，左中右各一次 → 半开匣盖可见不可取 → 一名监看到散会。不戴到脸上，不递观众席，不抛掷。备份镜架只应急、不上手传递。

## 5. 加冕道具（与主方案统一）

绶带：宽 80 mm，哑黑底钛金细边，绣 NIMO，无「冠军／战神」。  
勋章：Φ42 mm，背面刻称号与日期。  
第 10000 副：六人各触匣沿或绒垫 3 秒即还——荣耀经手，器物归公。  
权杖不作刀剑，不作军训举手过顶；若做，仅为缩小镜框轮廓，轻触即还。  
红包：哑黑信封钛金边，现金 888，现场不报「第几名」。

## 6. 直播与禁忌

三机：正中后全景、右侧 35° 加冕、左侧倒计时特写。游机只拍眼镜与托盘，不拍观众表情集锦。BGM 极弱垫乐，低于人声，不外放战歌。

不做军训方阵、不齐步、不强制晒红包、LED 不滚动 GMV、绿光不闪不轰。画面强调无摄像头、29 g、日常可戴，禁止拍成监控或游戏外设。
