# snow-brothers-3d

3D remake of **Snow Brothers** — game design + playable prototypes.

## Playable prototypes

| Stage | Theme | Path | Run |
| --- | --- | --- | --- |
| **11** | Crystal Cavern (World 2 opener) | [`stage-11/`](./stage-11) | `cd stage-11 && npm install && npm run dev` |

### Stage 11 controls

- **WASD / Arrows** — move
- **Space** — jump
- **J / Z** — throw snow
- **K / X** — kick snowball

Design notes: [`stage-11/docs/STAGE-11.md`](./stage-11/docs/STAGE-11.md)
